# n8n Enquiry Routing and Review Queue Demo

## Problem
Small businesses can miss or mishandle enquiries when leads arrive through forms, emails or messages.

## Solution
This workflow captures enquiry submissions, validates required fields, detects urgent keywords, routes valid enquiries to Airtable, sends Discord notifications, and sends problem records to a Review Queue.

## Tools
n8n, Airtable, Discord Webhooks, Docker

## Current Status
Learning portfolio project. Built and tested locally using synthetic data.

## Limitations
- Local n8n development setup
- Test data only
- Not deployed publicly yet
- Basic email/message validation
- Human review required for incomplete/problem records
